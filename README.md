# AI-Voice-agent
n8n, Orchestrator

An intelligent AI-powered Dental Voice Assistant designed to automate patient interactions, answer dental-related questions, provide treatment information, assist with appointment scheduling, and retrieve accurate clinic information using Retrieval-Augmented Generation (RAG).

## ✨ Features

| Category | Features |
|----------|----------|
| 🤖 **Artificial Intelligence** | Conversational AI, RAG, Semantic Search, Context-Aware Responses |
| 🎤 **Voice Interaction** | Voice Input, Speech-to-Text, AI Voice Responses |
| 📚 **Knowledge Management** | Website Crawling, Text Chunking, Embeddings, Pinecone Vector Search |
| 🦷 **Dental Assistance** | Treatment Information, Pricing Assistance, Dental FAQs |
| 📅 **Patient Services** | Appointment Assistance, Clinic Information, Consultation Guidance |
| 💾 **Memory** | Session-Based Conversation Memory |
| ⚙️ **Automation** | End-to-End Workflow Automation with n8n |
| 🌐 **Frontend** | Responsive Web Chat Interface |
| 🚀 **Scalability** | Modular Multi-Agent Architecture |
